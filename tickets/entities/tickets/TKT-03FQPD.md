## Description

An agent asks "(A) ... (B) ... which?". The poster should attach options to the
message; they render as buttons. Clicking one posts the declared answer type
with that choice; an "other" option opens free text. Today there is no
list-valued message property and no way to declare that a message's options
become reply buttons.
