## Description

First slice of FEAT-GWF8YH phase 1 (RES-1UCUBA).

- A change-feed `Bus` between the store watcher and SSE subscribers numbers each event in-process and keeps a bounded replay ring.
- SSE frames carry an opaque `id:` (encrypted sequence). A client reconnecting with `Last-Event-ID` gets the missed changes, gated per type as today, or a `refresh` with `reason: resync` when the ring no longer covers its position.
- Heartbeat comment every 25 s. The SPA passes its last event id on reconnect.
- Per-type ACL gating (TKT-POT9GQ) stays exactly as it is.

Design: PLAN-LMQR21.

## Out of scope

Store-level sequence numbers, per-subscription frames with entity ids
(TKT-HJ5Z9Y) and the MCP watch tool (TKT-FMS8BS).
