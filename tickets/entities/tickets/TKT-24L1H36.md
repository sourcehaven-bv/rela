## Description

Capture an item without leaving what you are doing. data-entry.yaml gains a
`quick_entry:` block naming a create form and, optionally, a list whose
`assign:` block supplies the defaults. The web app opens it with a keyboard
shortcut; the desktop app registers a global hotkey that opens it in a small
window, even when the app is in the background.

## Follow-up

Issue #2600: the guide listed `OptionOrAlt` as a modifier, but the validator refused it, although Wails accepts it. The validator now accepts `optionoralt`, and the guide also lists `Command`, which the validator already accepted.
