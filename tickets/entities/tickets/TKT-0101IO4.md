## Description

A string property that holds a URL renders as plain text on every surface.
Harbourmaster's invoice `pdf_url` is an example: a customer sees the address but
cannot click it.

Add a `link` display format for string properties (`display: {link: true}` in
schema.yaml) and a `url` widget. In display mode the widget renders the value as
a link that opens in a new tab with `rel="noopener noreferrer"`. In edit mode it
is a URL input. Only http, https and mailto targets become links; any other
value (javascript:, data:, a relative path) renders as plain text.

The widget is routed by the registry on every surface: detail pages, view
sections, list cells, kanban cards and forms. `widget: url` is also a valid
per-field override.

## Acceptance criteria

- `display: {link: true}` loads on a single-valued string property and is
refused elsewhere.
- Detail, view section, list cell and kanban card show the value as a link.
- Forms show a URL input.
- javascript:, data: and relative values render as text; mixed case and
leading whitespace are handled.
