id: RR-9017GL
type: review-response
title: Sidebar entity fetch ignores worlds and faces
finding: EntityList sends worldParam (EntityList.vue:461) and links carry ?world= (:682); useWorld folds in default_world. A sidebar mounted on every page would list default-world rows while the user browses another world and its links would drop the world.
severity: significant
resolution: The fetch includes worldParam, the query key includes it, it refetches on world change, and each link carries query.world. Rows and links are keyed with entityRef (face-aware), not the bare id.
status: addressed
