type: review-response
title: tags mode printed a blank line on an empty result
finding: 'scripts/check-tagged-tests.sh: `printf ''%s\n'' "${TAGS[@]:-}"` expands an empty array to one empty string, so `... tags` printed a single blank line rather than nothing. A caller piping to wc -l or xargs would count a phantom entry. The existing test passed only because $(...) strips the trailing newline, so it asserted the captured value while the actual output was wrong.'
severity: minor
resolution: 'Output is now guarded by an element-count check. Test asserts on `wc -l` rather than the captured string, so it checks the real output shape: "empty tag list prints no lines".'
status: addressed
