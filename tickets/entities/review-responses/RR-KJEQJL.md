finding: 'internal/store/fsstore/layout.go:667 normalizeSchemas checks only for an empty type name, and entityFileKey (layout.go:713) and scanTypeDir (index.go:569) join Plural under entitiesKey. path.Join cleans before RootedFS validates, so a plural of ".." or "../relations", "../.rela" or "../templates/entities" yields a clean key ("ID.md", "relations/ID.md") that RootedFS accepts: containment holds at the project root but not at the entities directory. entities.*.plural is on the Configure allowlist (internal/configedit/allowlist.go:73) with no value check, so a web principal holding config:edit, not only a shell operator, can set it. A changed plural on an existing type is refused by SetSchemas but is accepted by New on the next restart. Add a test with plural "../relations" and "..".'
