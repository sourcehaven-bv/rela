type: review-response
title: ListByLifecycle has no type filter so RunLifecycle is O(all channels) every minute
finding: ListByLifecycle(state, before) returns every channel of every type in that state older than the cutoff. On filechannels each call is a full visitAll tree walk, and A3 calls it per type and state, plus StalePending (also a full visitAll) every minute. That contradicts the O(due) budget in AC24. Add a type parameter (and a (tomb, type, state, since) index on the databases), skip StalePending when no action is declared, and make the budget test count fs walks.
severity: significant
resolution: ListByLifecycle takes a type. pg gains an index on (tomb, type, state, state_since) in a new migration and sqlite a matching schema version. StalePending runs only when a type declares actions. The budget test counts fs tree walks.
status: addressed
