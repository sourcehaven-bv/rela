title: Removed waiting message hides every decision button on the inbox row

severity: significant
resolution: InboxWaitingItem sets cause only for a present, non-removed message; decisions go onto the message only then, else the bare RlChannelDecisions bar renders, so reply_to never names a removed seq. Two InboxWaitingItem tests pin it.
