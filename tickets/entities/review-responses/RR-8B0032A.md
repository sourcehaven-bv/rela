title: 'Design: roll-up names break stored hash equals view hash'
finding: MergeRollups drops stored values under roll-up names and adds computed roll-ups, so a stored hash over such a value would be folded although no reader is served it (an offline oracle) and step 4 might hash a different view.
severity: significant
resolution: 'Plan changed: the reconcile doc defines the view as the redacted stored row without computed roll-ups. The scope contract requires every roll-up name of a type as a HiddenField with an empty condition, so a row holding a value under it is pending. Conformance case pins it.'
status: addressed
