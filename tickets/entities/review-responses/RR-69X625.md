When the operator changes the endpoints in the same schema edit, that delta is inside the file''s from→to and the chain completes; stored relations keep valid entity IDs, and endpoint conformance is advisory (analyze_cardinality). The real residue is UX: gen emits only a TODO comment for endpoint narrowing — acknowledged v1 limitation, documented in the generator output itself and docs/data-migration.md''s step table.'
