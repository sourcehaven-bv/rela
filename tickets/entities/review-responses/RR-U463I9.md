title: A command can mint a download token for .rela/secrets.yaml
finding: 'Security review: containment is the sole gate on what may be minted, and .rela/ lives inside the project root, so a `file` message naming .rela/secrets.yaml passes and becomes downloadable by every principal holding that command''s permission. The project rule ''secrets stay off the wire'' has no representation in this path. Realistic trigger is a backup or archive script globbing the project root, not deliberate abuse.'
severity: minor
reason: 'Not a new capability, and not specific to this ticket. A command script already has arbitrary shell: it can cat the same bytes into a `text` SSE message today, so the author-side exposure is unchanged. What the reviewer correctly identifies as new is narrower — the file becomes reachable by readers of the command without passing through the visible SSE transcript. That is worth closing, but a `.rela/` mint denylist is a rule about what command output may reference in general, and it belongs with the same question for the `text` path rather than bolted onto the download route alone. Deferred to its own ticket so it is decided once, for every channel, rather than patched here for one. Flagged to Jeroen rather than silently dropped.'
status: deferred
