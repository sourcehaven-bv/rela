type: review-response
title: Consolidating @keyframes spin broke RelationCards' spinner centring
finding: |-
    The keyframes consolidation dropped a load-bearing transform. RelationCards' private keyframes were NOT byte-identical to the others apart from the duration — they read:

        @keyframes spin { to { transform: translateY(-50%) rotate(360deg); } }

    The `translateY(-50%)` was re-applied deliberately, because `.search-spinner` centres itself vertically with `position: absolute; top: 50%; transform: translateY(-50%)`, and an animated `transform` REPLACES the static one for the animation's duration. The shared keyframes rotate only, so the spinner dropped half its height the instant it started animating and then rotated about a displaced centre.

    The 0.6s duration — the difference I had noticed and preserved — was the trivial one. `pending.css` asserted the copies were 'byte-identical except for RelationCards' 0.6s', and that false claim is exactly why this shipped: the blocks were compared by eye rather than diffed.
severity: significant
resolution: |-
    Centred `.search-spinner` with `margin-top` instead of a translate, leaving `transform` free for rotation alone — the restructure the reviewer preferred over reinstating private keyframes, since it removes the coupling rather than re-hiding it.

    The browser caught an arithmetic error in the fix: I wrote -10px (half of 16px + 2px borders), but `box-sizing: border-box` is global in App.vue, so the 16px height already includes the borders and the correct value is -8px. The first attempt measured a 2px offset rather than the expected 0.

    Added an e2e test that measures the spinner's centre against its offset parent's MID-ANIMATION (via `getAnimations()` + `currentTime`), which is the only way to observe a transform-clobbering regression — a static CSS read cannot see it. Built as a standalone fixture so it tests the CSS geometry rather than relation-search timing.

    The false 'byte-identical' claim was removed from pending.css.
status: addressed
