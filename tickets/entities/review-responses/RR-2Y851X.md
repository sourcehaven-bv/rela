type: review-response
title: Program cache key must include metamodel/layout, not just (source,type)
finding: 'Plan proposes caching compiled Programs by (source,type). Same (source,entityType) yields DIFFERENT Programs across metamodels: EntityRecordType bakes the field date layout into DateTypeWithLayout(prop.GetDateFormat()) (predicatefns/env.go:59) and the declared field set. Project A ticket.due layout 2006-01-02 vs Project B 01/02/2006 give the same key but must not share a Program. A process-global sync.Map cache poisons across projects / parallel tests. FIX: scope the cache to the metamodel/resolver instance (like affordances'' per-resolver envs map[string]*predicate.Env, resolver.go:69,192-202). If global, key must include a metamodel fingerprint or the resolved RecordType, not the type name.'
severity: significant
resolution: The Program cache lives on predicatefns.Evaluator, which is bound to ONE *metamodel.Metamodel at construction (NewEvaluator(meta, now)) and keyed by (entityType + NUL + source). Because each Evaluator instance is metamodel-scoped, two projects with different field layouts/date formats get separate Evaluators and cannot share a Program — the process-global (source,type) poisoning the finding warned about is structurally impossible. CLI builds one Evaluator per applyListFilters call; automation Engine and validation Service each hold one lazily-built Evaluator rebuilt when their metamodel changes (Engine.SetMetamodel resets it). Evaluator is mutex-guarded, concurrency-safe.
reason: Deferred to phase 2b (TKT-J4IR1G), where the Program cache is actually introduced (--filter compile-once + automation/validation compile-on-load). Phase 2a (this PR) adds no Program cache — the transpiler FromFilter returns source that the caller compiles, and the only caller so far is tests. The cache-scoping requirement (key on metamodel/resolver instance, not process-global (source,type)) is captured in TKT-J4IR1G's scope so it lands with the cache itself. Nothing to cache-key in phase 2a.
status: addressed
