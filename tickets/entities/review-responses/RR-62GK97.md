type: review-response
title: Expanding the tail fold scrolls past the start of the run
finding: 'While the reader is at the bottom (stuck), the ResizeObserver on the list (RlChannel.vue:293-297) calls scrollToBottom whenever the list grows. Expanding the tail run, which is the common case because progress collects at the end, therefore scrolls to the newest progress message. The fold button and the start of the run leave the viewport, although the reader wanted to read from the top. Change the plan: on expand, set stuck to false and keep the fold button where it was (anchor on it), and state the expected scroll position in AC 5.'
severity: significant
resolution: Expanding or collapsing a fold sets stuck to false and anchors on the fold row, so the button keeps its offset and the run opens below it (step 6). AC 5 now states this expected scroll position, and the story checks it for the tail fold.
status: addressed
