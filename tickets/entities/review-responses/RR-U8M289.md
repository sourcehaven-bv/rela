title: Started flag is set before the started write succeeds
finding: 'internal/realtime/outputs.go:579-583: started = true is set before e.write. If that write fails transiently (the writer returns WroteNothing), runOne enters the started branch, tries a second write to drop the record and, if that also fails, records unconfirmed for a create that never ran. If the done write later succeeds, the create is lost and reported as unconfirmed. Fix: set started only after e.write returns nil.'
severity: minor
resolution: started is set only after the started record is stored; a test injects a failing SetAction and expects a retry, not unconfirmed.
status: addressed
