title: Compile-time literal coercion is the load-bearing design choice
finding: 'The plan''s core mechanism (preserve predicate''s no-I/O-at-eval invariant, AC8) depends on typing date/integer RHS literals at COMPILE time against the LHS field''s declared type: e.g. `entity.due < ''2026-02-01''` — the RHS string literal is parsed to a Date at compile because the walker knows `due` is DateType from the Env. This requires new logic in walkRelational (compile.go) to inspect the LHS resultType and coerce a string/number literal RHS accordingly, using metamodel.ParseDateValue at compile (not eval). This is the single hardest and most load-bearing part of phase 1: if the two operands are e.g. two record attrs (not a literal), or the literal is on the LHS, coercion direction must be handled; and coercion must run at compile so eval stays pure. The rejected fallback (bind-time typed Values, RES-6PK0S3 fork option b) re-scatters the metamodel-aware typing logic across every call site — exactly the fragmentation this ticket removes. Action: prototype walkRelational coercion FIRST, before committing the rest of phase 1; if it proves infeasible, re-open the fork decision rather than silently falling back.'
severity: significant
resolution: 'Prototyped and verified. walkRelational now calls coerceLiteralOperands after walking both sides: when one operand is an Int/Date-typed expr and the other a bare literal constNode, the literal''s boxed Value is retyped at COMPILE time (number->int64 via coerceIntLiteral rejecting non-integers; string->time.Time via coerceDateLiteral/parseDateLiteral). Coercion is symmetric (either side may be the literal). Date layout is carried on the type descriptor via DateTypeWithLayout(layout) (equalsType-compatible with the bare DateType singleton) so predicate need not import metamodel; parseDateLiteral tries the field layout then default layouts (2006-01-02, RFC3339). Eval stays pure (no parse/no metamodel at Eval) preserving the arch invariant. Verified by internal/predicate/typed_coercion_test.go: int numeric ordering (100>9 true), instant-granular dates, cross-type or-composition, and compile-time rejection of malformed date / non-integer int literals. Fallback (bind-time typing) not needed.'
status: addressed
