id: RR-89F61L
type: review-response
title: Command-confinement global read before appbuild.Discover (ordering trap)
finding: cmd/rela-server/main.go applied SetUnconfinedByDefault AFTER discoverProject, but appbuild.Discover may construct a cmdexec.Runner which reads the process-global unconfinedByDefault at construction. A future runner built inside Discover would read the default before the flag was applied, silently confining (or failing closed on) a host the operator explicitly opted out of, with no error.
severity: significant
resolution: Moved applyCommandConfinement above discoverProject in main(), with a comment documenting the load-bearing ordering. The confinement decision is now recorded before any services (and thus any runner) are built.
status: addressed
---
