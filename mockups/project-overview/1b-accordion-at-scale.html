What this costs per page. The existing list page is pinned at 6 store reads regardless of page size (scoped count, one bounded page read, page edges, neighbour headers, membership walk) by TestQueryBudget_ListPageIsSizeIndependent. This view adds one rollup-count query, plus one task-header query per expanded epic — still constant in the number of epic rows, not one query per row. Task bodies are never loaded: these rows need only id, title, status, due and owner, which is exactly what store.EntityHeader carries.
