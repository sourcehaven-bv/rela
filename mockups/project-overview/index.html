Project → epic → task overview

Five static mockups of a nested project overview: open a project, see every epic with a done/ongoing rollup, and drill into the tasks underneath. Same fake data throughout (PRJ-4417 "Harbour Migration", 6 epics, 48 tasks) so the layouts are directly comparable. Colours are rela's real design tokens; the button top-right toggles dark mode.

1 · Accordion

Closest to today's list view

Collapsible epic rows, each with its own rollup bar; tasks indent underneath the open one.

+Scales to many epics; collapsed by default
+Degrades cleanly to a narrow screen
−Can only compare epics you've opened
Open mockup See it at scale →

2 · Swimlanes

Kanban, one lane per epic

Board with a lane per epic and a column per status, so progress reads left-to-right.

+Natural drag-and-drop to change status
+Bottlenecks are visible as a tall column
−Hungry for horizontal space; long scroll
Open mockup

3 · Tree table

Densest; report-shaped

One table, epics as parent rows carrying derived rollups, tasks as indented children.

+Sortable, selectable columns, CSV export
+Most information per screen
−Reads as a spreadsheet, not a status view
Open mockup

4 · Epic cards

Weekly status read

A tile per epic with a donut rollup and only the tasks that need attention — late, blocked, in flight.

+Fastest answer to "which epic needs me?"
+Reflows to any width for free
−Never shows the full task list
Open mockup

5 · Timeline

Schedule and sequencing

Epic-level gantt, each row expanding into its task bars, with a today marker.

+Only variant showing overlap and slippage
+Extends rela's existing gantt view
−Needs start + due dates on everything
Open mockup

6 · Detail widget

Integration, not a new layout

Variant 1 as one ViewSection on the ordinary entity detail page, between the properties and relation-card sections.

+No router, sidebar, endpoint or ACL work
+Upgrades a section a project page already has
−Section wire format is flat; needs a nesting shape
Open mockup
